# Mah Jongg Medieval (Android)

Projeto inicial de recriação jogável do Mah Jongg para Windows 3.x, com tabuleiro de 144 peças, toque, seleção/remoção de pares, contador, cronômetro, som e reinício.

## Gerar APK

O workflow `.github/workflows/android-apk.yml` compila automaticamente em cada push para `main` e publica o APK debug como artefato da execução. Abra a aba Actions do repositório e baixe `mahjongg-medieval-debug-apk` quando a execução terminar.

## Estado atual

Este é um protótipo de jogabilidade. As peças usam desenhos vetoriais medievais provisórios, não a arte original decodificada de `MEDIEVAL.TIS`; a posição do tabuleiro ainda precisa ser ajustada contra a captura de referência. O APK deve ser instalado e testado em dispositivo antes de considerar a versão validada.
